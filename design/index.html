Pibo UI Kit

Pibo 와 PiBrain 의 IDE · Tools · Classifier 가 같이 쓰는 스타일 한 벌. 빌드 없이 <link> 한 줄. 지금 배색과 분위기를 그대로 유지한다.

이 키트가 바꾸는 것은 색이 아니라 위계다 노랑·청록·빨강 값은 기존 그대로 쓴다. 다만 노랑을 아껴 쓴다 — 헤더와 '지금 눌러야 할 버튼 하나'에만. 그래야 노랑이 강조로 작동한다. 지금은 헤더도 버튼도 입력창도 전부 노랑이라 강조할 것이 남아 있지 않다.

1   색

세 앱이 이미 같은 변수 9개를 각자 선언하고 있었다. 이 키트는 그걸 한 파일로 합친 것이다.

--yellow#f4de3d
--dark-yellow#f4d85a
--light-yellowrgb(248,242,172)
--teal#13bfd5
--dark-teal#11abbf
--red#f16449
--dark-red#d85a41
--light-green#edf5e0
--mid-gray#6c6c6c
고치면서 발견한 어긋남 --teal 이 ide·classifier 는 #13bfd5(19,191,213) 인데 tools 만 rgb(18,189,212) 다. 1씩 다르다. 눈에는 안 보이지만 세 파일에 손으로 복사해 온 결과다. 이 키트는 #13bfd5 로 통일한다.

컴포넌트는 브랜드 색을 직접 쓰지 않는다

역할 토큰을 거쳐 쓴다. 나중에 배색을 바꿀 때 한 줄만 고치면 된다.

역할 토큰지금 값쓰는 곳
--pb-brand--yellow헤더 띠, 상태바. 정체성
--pb-accent--yellow한 화면에 하나. 지금 눌러야 할 버튼
--pb-danger--red초기화·종료처럼 되돌릴 수 없는 것
--pb-info--teal안내 표시. 동작 버튼에는 쓰지 않는다
--pb-surface#f7f7f7툴바·패널 바닥
--pb-focus#0b63c4키보드 포커스 링. 흰 배경 대비 6.4:1

3   아이콘 버튼 — 글자 라벨을 반드시 같이

태블릿에는 hover 가 없다 지금 IDE 헤더 아이콘에는 title 이 이미 붙어 있다 (templates/index.html:51-70). 그런데 터치 기기에서는 툴팁이 뜨지 않는다. 게다가 title 값이 영문 하드코딩이라 ko2en.js 번역을 타지 않는다.
도구 대화 분류기 도움말 전체화면 더보기

전원·공장초기화는 더보기 안으로 넣는다. 지금은 도움말·전체화면과 같은 크기로 나란히 있어서 태블릿 오탭 한 번이면 닿는다. 확인창은 있지만, 확인창은 마지막 방어선이지 첫 방어선이 아니다.

6   글자

--pb-font 는 앱(ide·tools·classifier)이 원래 쓰던 스택과 같다. 키트 컴포넌트가 앱 본문과 다른 글꼴로 튀지 않게 하려는 것이다.

키트는 앱 본문 글꼴을 바꾸지 않는다 한때 system-ui 스택을 .pb(= body)에 걸었더니 파일 목록·경로·상태바까지 앱 전체가 16px Helvetica/맑은 고딕 → 15px system-ui 로 바뀌었다. 지금 .pb 는 범위 표시일 뿐이고, 글꼴은 키트 컴포넌트에만 건다. 글꼴을 바꾸려면 --pb-font 만 고친다.
알고 있는 문제 (고치려면 따로 결정) ① 앱 스택은 Helvetica 가 앞이라 라틴과 한글이 다른 글꼴로 그려진다. "맑은 고딕" 은 윈도우 전용이다.
② "Noto Sans Regular" 가 앱 CSS 에 쓰였지만 어디에도 로드되어 있지 않다(항상 폴백).
③ html { font-size: 10px } 는 브라우저 글자 크기 설정을 무력화한다.

7   쓰는 법

원본은 하나

design/pibo-ui.css 뿐이다. 각 앱의 static/ 에 있는 사본은 design/sync.sh 가 복사한다. static/pibo-ui.css 를 직접 고치지 말 것 — 다음 sync 에 덮인다.

./design/sync.sh                     # 이 리포의 ide·tools·classifier 로 복사
./design/sync.sh ~/openpibo-os.pibrain   # PiBrain 체크아웃으로도 복사
./design/sync.sh --check             # 어긋난 사본이 있는지만 확인 (CI·커밋 전)

앱에 붙이기

<link rel="stylesheet" href="../static/pibo-ui.css?ver=YYMMDDvN">
<body class="pb">

class="pb" 가 있는 안에서만 적용된다. 기존 index.css 와 같이 두고 화면 단위로 천천히 옮겨도 충돌하지 않는다. 한 번에 다 갈아엎지 않아도 된다.
